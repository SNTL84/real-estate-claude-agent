## 🎯 What Is This?

An **AI agent** built on Claude's 4-layer architecture that provides intelligent property valuation and investment analysis specifically for **Surat, Gujarat, India** — one of India's fastest-growing tier-2 cities.

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🧠 AI Valuation | Claude-powered property price estimation |
| 📊 Investment Analysis | ROI, rental yield, capital appreciation |
| 🏙️ Locality Intelligence | Surat micro-market data & trends |
| 📈 4-Layer Architecture | Perception → Reasoning → Action → Memory |
| ⚡ TypeScript | Fully typed, production-ready code |
| 🌐 Deployable | Vercel/Netlify ready |

## 🏗️ Architecture

```
Layer 1: Perception    — Input parsing, property data extraction
Layer 2: Reasoning     — Claude AI analysis & valuation logic  
Layer 3: Action        — Report generation, recommendations
Layer 4: Memory        — Session context, comparison history
```
